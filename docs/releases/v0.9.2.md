# FairTranslator v0.9.2

Patch release focused on RPG Maker MV export correctness and Japanese-to-Spanish
QA hardening discovered during a full-game translation pass.

## Highlights

- Preserves choice/plugin condition prefixes such as `if(s[12])` and
  `en(s[20])` in prompts and integrity checks, preventing translated DSL from
  breaking conditional choices.
- Adds Japanese-to-Spanish prompt guidance for natural Spanish, concise RPG
  Maker UI labels, Spanish punctuation, credits/staff rolls, and concrete
  calque traps such as `学校の帰り道` and `一人称`.
- Wraps long MV/MZ show-text translations, splits oversized text into multiple
  message windows, and inserts a final choice prompt when needed so choices do
  not appear before the player finishes reading.
- Patches exported name-input plugins that used unsupported browser `prompt()`
  calls so they use RPG Maker's built-in name scene.
- Restores RPG Maker asset references to the exact copied filenames after
  export, fixing encrypted `.rpgmvp` image loading failures caused by
  whitespace-width differences in data references.
- Applies plugin source fallback translations for visible menu defaults such as
  game-exit labels when plugin parameters are empty.

## Validation Snapshot

Validation run for this release included:

- `cargo fmt`
- `git diff --check`
- `cargo test exporter -- --nocapture`
- `cargo test compact_prompt -- --nocapture`
- `cargo test translation_integrity -- --nocapture`
- `cargo test translation_orchestrator -- --nocapture`

The full Rust suite was started during manual QA but interrupted while
investigating game runtime errors. The focused tests above cover the changed
exporter, prompt, integrity, and planning paths.

## Known Limits

- In-game visual QA is still required for translated games because RPG Maker
  plugins and event scripts can introduce project-specific display behavior.
- Missing template enemy graphics (`Bat`, `Slime`, `Orc`, `Minotaur`) were also
  absent in the original RJ01568532 game data and are not introduced by this
  release.
