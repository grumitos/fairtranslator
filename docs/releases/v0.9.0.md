# FairTranslator v0.9.0

Initial public release for FairTranslator as a desktop translator for RPG Maker games.

## Supported Engines

- RPG Maker MZ
- RPG Maker MV
- RPG Maker VX Ace
- RPG Maker VX
- RPG Maker XP

## Highlights

- `.fairtl` project format for translation work in progress
- Parser and exporter coverage for the supported RPG Maker engine set
- Grid-based translation workflow with status tracking and glossary support
- Built-in translation providers for OpenAI, DeepL, Google Translate, and Codex
- Structured external AI batch export/apply flow
- Safe export into a copied output directory instead of modifying the source game

## Known Limits

- Windows-first release distribution
- Scope limited to the supported RPG Maker engines listed above
- The standard release expects a local Codex runtime installed or available on `PATH`
- Sidecar-based Codex bundling is supported by the codebase, but not enabled in the default release workflow

## Validation Snapshot

Validated locally before release with:

- `cargo check`
- `cargo test`
- `npm run test:run`
- `npm run build`
